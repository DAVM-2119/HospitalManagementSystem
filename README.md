Hospital Management System (HMS)
A console-based Java application for efficient hospital management.
User Roles:

Receptionist – Add/delete users, generate bills
Doctor – View appointments, prescribe medicine, update status, send notifications
Pharmacist – Manage inventory, dispense medicine, update stock
Patient – Book appointments, view prescriptions, pay bills, receive alerts

Key Features:

Secure login & registration
Appointment scheduling with status tracking
Prescription & billing system
Pharmacy inventory control
Doctor-to-patient notifications
All data saved in .txt files (persistent storage)

Tech: Java (OOP, File I/O)
javac HospitalManagementSystem.java
java HospitalManagementSystem
